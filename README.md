# AI Fashion Assistant

Gemini API 기반의 AI 옷장·코디 추천·가상 피팅 Flutter 앱입니다.
내 옷을 등록해두면 AI가 속성을 자동으로 분석하고, 체형 정보와 비교해 핏을 예측하고, 실제로 입어본 것 같은 가상 피팅 이미지를 생성해줍니다. 여기에 더해 캘린더 일정을 감지해 코디를 미리 추천해주는 백그라운드 AI 에이전트가 함께 동작합니다.

## 소개

옷장 정리부터 코디 조합, 착용 시뮬레이션, 일정 기반 코디 자동 추천까지 한 곳에서 해결하는 것을 목표로 하는 개인 패션 도우미 앱입니다.

- 옷 사진 한 장만 등록하면 카테고리·색상·스타일·패턴·격식을 AI가 자동으로 추출
- 체형 프로필과 옷 치수를 비교해 타이트/정핏/오버핏 여부를 미리 확인
- Gemini API로 사용자 사진에 옷을 합성한 가상 피팅 이미지 생성
- 옷장 아이템을 조합해 나만의 코디보드 구성
- 캘린더에 일정(TPO)을 등록해두면 에이전트가 격식에 맞는 코디를 미리 준비하고, 자기 평가·수리 루프로 품질을 검증
- 에이전트가 어떤 판단을 내렸는지 활동 로그로 투명하게 확인 가능

## 주요 기능

### AI 옷장
옷을 촬영/업로드하면 배경 제거 후 AI가 카테고리, 색상, 스타일, 패턴, 격식 등 속성을 자동으로 추출해 Firestore에 캐싱합니다. 이후 분석 시에는 이미지를 재전송하지 않고 저장된 속성 텍스트를 활용해 응답 속도를 높였습니다. 아이템 카드에서는 같은 카테고리 내에서 임베딩(FashionCLIP 벡터) 기반으로 시각적으로 비슷한 옷도 함께 보여줍니다.

### 사이즈 입력 & 예상 핏 예측
사이즈표를 캡처하면 OCR로 치수를 자동 인식해 입력하거나, 직접 치수를 입력할 수 있습니다. 저장된 체형 프로필과 옷 치수를 규칙 기반으로 비교해 타이트/정핏/오버핏 뱃지를 옷장 카드에 표시합니다.

### AI 가상 피팅룸
사용자 사진과 선택한 옷들을 Gemini API에 전달해 실제로 착용한 것 같은 합성 이미지를 생성합니다. 분석/생성은 백그라운드에서 진행되어 다른 탭으로 이동해도 작업이 유지되고, 진행 상황은 화면 위 플로팅 아이콘으로 계속 확인할 수 있습니다.

### 코디보드
아우터, 상의, 하의, 신발, 액세서리(모자·가방·시계·팔찌) 등 슬롯 단위로 옷장 아이템을 배치해 코디를 조합하고 저장할 수 있습니다.

### 착장 캘린더 & AI 코디 에이전트
캘린더에 날짜별 일정(출근·데이트·여행·운동·모임·결혼식·면접·경조사·일상 등 TPO 태그)을 기록하면, 백그라운드 에이전트가 앱 실행 시점에 다가오는 일정을 감지해 옷장에서 격식에 맞는 코디 조합을 미리 준비합니다.

- **자기 평가 루프** — 후보 조합을 Gemini로 순차 평가해 기준 점수를 넘으면 바로 채택하고, 미달이면 원인(격식/색상/스타일 중 가장 약한 축)을 진단해 해당 아이템만 교체 후 한 번 더 평가합니다.
- **실패 대응** — 격식에 완전히 맞는 조합이 없으면 가장 가까운 차선책으로 대체하고 어떤 카테고리가 부족했는지 안내하며, 아우터·신발처럼 조합에는 포함됐지만 격식이 애매한 선택 아이템이 있으면 그 사실도 별도로 알려줍니다.
- **날씨 반영** — 예보(강수/기온)를 관찰해 코디에 반영하고, 예보가 이후 유의미하게 바뀌면 추천을 자동으로 재계획합니다.
- **피드백 학습** — 사용자가 추천대로 입었는지/다른 조합을 골랐는지를 감지해 이후 추천 프롬프트와 자기 성능 인지 문구("이 코디는 자신 있어요" 등)에 반영합니다.
- **주간 코디 플랜** — 버튼 한 번으로 앞으로 7일치 일정에 맞는 코디를 한꺼번에 계획받아 날짜별로 확정할 수 있습니다.

### AI 비서 활동 내역
설정 화면에서 에이전트가 언제 무엇을 감지하고, 어떤 근거로 어떤 코디를 추천했는지 시간순 로그로 확인할 수 있습니다.

### 스크랩
피팅룸에서 마음에 든 가상 피팅 결과를 북마크해두고 설정 화면의 "내 스크랩"에서 모아볼 수 있습니다.

### 체형 프로필
퍼스널 컬러, 체형, 선호 스타일 등을 입력해 핏 예측과 코디 추천의 기준으로 활용합니다.

### 계정 & 저장
Firebase Authentication(익명 로그인), Firestore, Firebase Storage, App Check를 통해 옷장 데이터와 이미지를 안전하게 저장합니다.

## 화면 구성

하단 탭 5개(홈 · 옷장 · 피팅룸 · 캘린더 · 설정)를 중심으로, 설정 화면에서 체형 프로필/내 스크랩/AI 비서 활동 내역으로 이동합니다.

## 기술 스택

- **Framework**: Flutter
- **AI**: Google Gemini API (`google_generative_ai`)
- **Backend**: Firebase (Authentication, Firestore, Storage, App Check)
- **이미지 처리**: `image_picker`, `image_cropper`, `image_background_remover`(배경 제거, `tflite_flutter` 교체 검증 중), `cached_network_image`
- **캘린더**: `table_calendar`

## 프로젝트 구조

```
lib/
  screens/    화면(홈, 옷장, 피팅룸, 캘린더, 설정, 체형 프로필, 스크랩, 활동 로그 등)
  services/   Gemini/Firestore 연동, 코디 매칭·자기평가, 에이전트 파이프라인, 날씨
  models/     Firestore 문서 매핑 모델
  widgets/    화면 간 공유 위젯(캘린더 기록 시트, 주간 플랜 시트 등)
  constants/  TPO 태그, 색상 팔레트, 스타일 팁 등 고정 데이터
tools/        Firestore 데이터 점검/이관용 오프라인 Python 스크립트(앱 코드와 무관, 각자 README 참고)
```

## 시작하기

```bash
flutter pub get
flutter run
```

Gemini API 키 등 민감한 값은 `lib/config/env.dart`(git 추적 제외)에 별도로 관리합니다 — 아래 형태로 직접 만들어야 합니다.

```dart
class Env {
  static const String geminiApiKey = 'YOUR_GEMINI_API_KEY';
}
```

테스트는 다음으로 실행합니다.

```bash
flutter test
```

일부 테스트(`test/*_report_test.dart`, `color_rule_verification_test.dart` 등)는 로컬 실측 옷장 데이터(`tools/export_for_kaggle/output/items.json`, git 추적 제외)가 있을 때만 실행되고 없으면 자동으로 스킵됩니다.
