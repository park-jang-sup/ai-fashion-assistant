### 11-1. 문구 (`c9d754d`)

### 11-2. 음성 입력 (`3960020`, 다듬기 `7f208c9`)
- **speech_to_text 7.4.0**. 최신 안정판 7.5.0은 Flutter 3.44·Dart 3.12가 필요한데 지금 SDK는 3.41.6/3.11.4라 받을 수 있는 최신으로.
- AndroidManifest(패키지 문서 그대로): RECORD_AUDIO, INTERNET, BLUETOOTH, BLUETOOTH_ADMIN, BLUETOOTH_CONNECT, queries `android.speech.RecognitionService`. 실행 중에는 `androidNoBluetooth`로 마이크 권한만 묻는다.
- 권한은 버튼을 처음 누를 때만. 화면을 열 때는 권한이 이미 있을 때만 초기화해 지원 여부를 안다(패키지가 권한 없이 지원 여부를 알려 주지 않음). 거절이면 한 줄 안내, 지원 안 함·초기화 실패면 버튼 숨김.
- 이어서 말하기·질문에 답하기 입력창에도. 보내기·턴 시작·질문 끝·화면 이탈 때 멈춤. 자동으로 보내지 않음. `VoiceEngine`으로 감싸 테스트에서 가짜로.
- **다듬기 — 앞에 말한 글이 사라짐의 원인**: 결과가 올 때마다 입력창 전체를 "시작 글 + 최신 결과"로 바꿔 썼다. 안드로이드 인식기는 말이 끊기면 앞을 한 구간으로 확정(intermediate)하고 다음 결과에는 새 구간만 보낸다. 또 기기 인식이 끝나면(done) 듣기도 끝냈다.
- 고침: 입력창 = 시작 글 + 확정 글 + 임시 글. 누적형 결과는 앞부분을 떼어 겹치지 않게. 기기 인식이 끝나도 켜져 있으면 이어 듣기(250ms 뒤), 6초 새 말 없음·켠 뒤 60초면 끔, 손으로 고치면 멈춤.
- 듣는 중 표시: 마이크를 감싼 원이 소리 크기(onSoundLevelChange, rms dB → 0~1)로 커졌다 작아짐, 값이 없으면 1.2초 맥박. 꺼지면 회색·정지. Transform만이라 입력창·보내기 자리 그대로.
- 이어 들을 때 알림음: 패키지 문서상 안드로이드가 시작·멈춤 때 시스템 소리를 내고 끌 방법이 없다 — 이어 들을 때마다 시작음이 다시 날 가능성이 높다(폰 확인은 사용자).
- iOS는 범위 밖. 필요한 것: Info.plist `NSMicrophoneUsageDescription`, `NSSpeechRecognitionUsageDescription`.

### 11-7. 서버 날씨 getForecast (`12d0aff` 함수, `0428766` 앱)
- 함수(asia-northeast3, onCall): 로그인 필요, 인자는 지역 키(앱 region_presets 이름) 하나 — 좌표는 받지 않음. 키 없으면 서울, 목록 밖이면 invalid-argument. 서버 지역 표 `functions/src/forecast_regions.ts`는 앱 목록에서 만들고 대조 테스트를 둠.
- 앱과 같은 Open-Meteo 요청, 8초 제한·시간 초과/통신 오류면 한 번 더. 기억 `forecast_cache/{지역 키}`(규칙에 match 없음 → 클라이언트 기본 거부, 규칙 변경 없음). 30분 안이면 기억, 날씨 서버 실패 때 6시간 안의 기억, 없으면 unavailable. 응답에 fetchedAt·source.
- uid별 시간당 120회 상한(`forecast_rate/{uid}`, 판정 실패는 허용). 로그는 지역 키와 결과만(uid 없음). 함수 테스트 13건 — 처음엔 시간 제한 테스트가 이벤트 루프가 비어 조용히 끝나 통과로 보였다(AbortSignal.timeout 타이머가 루프를 붙잡지 않음) → 붙잡는 타이머와 "끝나지 않은 테스트가 있으면 실패" 장치를 넣음.
- 앱: getForecast(8초) 먼저, 실패하면 직접 요청(동작 그대로). 같은 지역 동시 요청 합치기. 홈 실패 때 "다시 시도", 날씨 칸을 누르거나 앱이 앞으로 나오면 다시 받음. 에이전트 도구·백그라운드는 같은 WeatherService라 그대로(모델에게 가는 글 그대로).
- 배포 뒤 로그인 없는 호출 401 UNAUTHENTICATED 2/2. 폰에서 첫 실행 `fresh`, 둘째 `cache`, 실행마다 요청 1회.
- 되돌리기: `firebase functions:delete getForecast --region asia-northeast3`(실행하지 않음) — 지우면 앱이 스스로 직접 요청으로 넘어간다. `forecast_cache`·`forecast_rate`는 콘솔에서 지움.
